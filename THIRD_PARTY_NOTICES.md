# Third-party components

Release archives bundle the official CPython Windows embeddable distribution, version 3.14.6, downloaded from Python.org. Its complete license is retained as `runtime/LICENSE.txt` inside each release archive.

- Source and checksum: [`runtime-source.json`](runtime-source.json)
- Release: https://www.python.org/downloads/release/python-3146/
- License documentation: https://docs.python.org/3.14/license.html

The source repository does not vendor CPython or any Codex / OpenAI application binary. The launcher discovers the user's installed Codex runtime. OpenAI and Codex names identify the compatible application; this project is independently maintained.
